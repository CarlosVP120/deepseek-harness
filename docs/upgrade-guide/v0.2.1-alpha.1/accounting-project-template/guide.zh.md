# 新项目默认包含会计说明

[English](guide.md) | 中文

## 变更

通过工作区控制器创建新的项目注册时，如果所选目录没有 `AGENTS.md`，会在注册前将通用西班牙语会计模板写入该文件。原生代理执行继续将此文件作为项目说明加载。现有说明文件（包括空文件）保持不变。现有注册和首次使用时的默认工作区初始化不变。

## 迁移

1. 创建或关联新的项目目录，并打开项目设置查看初始说明。
2. 如果模板不适合项目，可在项目设置中编辑或清空说明；保存会持久化完整替换内容。
3. 关联目录时若要保留其说明，保留现有 `AGENTS.md`。重新关联已注册项目不会重置说明。
