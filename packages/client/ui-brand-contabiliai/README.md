# @deepseek-ai/dsh-client-ui-brand-contabiliai

Occupies the `sidebar.brand.mark`, `sidebar.brand.name` and `conversation.hero.brand.mark` slots with the FiscalCFDI symbol and the FiscalCFDI AI name. The `@deepseek-ai/dsh-contabiliai-app` bundle mounts it in place of `@deepseek-ai/dsh-client-ui-brand-official`; no configuration.
